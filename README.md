# Házi feladat: Superpowers vs BMAD

A repo ugyanazon feladat 2 megoldását tartalmazza Superpowers (`harness/superpowers` branch) illetve BMAD (`harness/bmad` branch) használatával.

A `main` branch csak dokumentációkat és a seed file-t tartalmazza. Az implementációk a két említett branchban találhatóak.

A `docs/dolgozat.md` file tartalmazza a két megoldás összehasonlítását a megadott kérdések alapján.
